Temperature Sensing & Visualization System

An Arduino temperature monitor that reads a thermistor, shows the temperature on an LCD, sounds a buzzer past a threshold, and streams data to a Python live plot that logs every reading to CSV.

Type
Personal project
Dates
Nov 2025 – Jan 2026
Controller
Arduino Uno
Sensor
Thermistor (analog)
Software
Embedded C/C++, Python, Matplotlib
GitHub repository

1Demo

In the demo I run the Python script on my laptop. It prints the three modes and asks Enter Mode:, then sends my choice to the Arduino over USB serial.

The LCD shows the live reading: 74.00 °F at room temperature. When I hold the thermistor, the reading climbs to 80.15 °F.

3What I built

Embedded systems

Programmed the Arduino Uno to handle sensor input, mode selection, LCD output, and buzzer control with structured control logic.

Sensor & circuit

Built the thermistor sensing circuit and converted analog voltage readings into temperature with calibration equations.

Data & visualization

Wrote a Python script that reads the serial stream, plots temperature and alert state live with Matplotlib, and saves readings to CSV.

Results

  • Measured and displayed temperature in real time
  • Reliable buzzer alerts at the set threshold
  • Live plotting and CSV logging for analysis and debugging
  • Modular enough to add more sensors
